## What this is

Public docs for **`@aisdkagents/react`** — headless behavior primitives for AI SDK agent interfaces — plus a **shadcn registry** for composition examples.

Paid Pattern / pro-block application source stays in the private catalog. This site is primitives + docs + public registry examples only.

## Install

```bash
pnpm add @aisdkagents/react
```

## npm vs registry

| Path | What you get |
| --- | --- |
| **npm** `@aisdkagents/react` | Canonical headless behavior |
| **shadcn registry** | Copy-in composition examples that depend on the package |

See [Registry](/docs/registry) for CLI install details.
