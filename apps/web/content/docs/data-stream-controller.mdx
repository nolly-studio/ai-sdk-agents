
```bash

```

Or the skin alone:

```bash
npx shadcn@latest add https://<your-deployed-host>/r/data-stream-controller.json
```

## Anatomy

1. **Root** — owns one Root-lifetime FIFO store; append must not rerender the tree.
2. **Handler** — sole drain owner. Receives `onPart({ part })` and optional `onError({ cause, part })`. Claim-before-dispatch, FIFO order.
3. **useAppend** — stable `append` for `useChat({ onData })`. Use **useController** for `append` / `appendMany` / `clear`.
4. **useStatus** — `pendingCount` / `hasPendingParts` only. No public drain, subscribe, or store.

## Quick start

```tsx
import { DataStreamController } from "@aisdkagents/react";

function App() {
  return (
    <DataStreamController.Root>
      <DataStreamController.Handler
        onPart={({ part }) => {
          // sink
        }}
      />
      <ChatIngress />
    </DataStreamController.Root>
  );
}

function ChatIngress() {
  const append = DataStreamController.useAppend();
  // useChat({ onData: append })
  return null;
}
```

## Registry skin

`Frame` / `Status` / `Log` / `Clear` are styled-only helpers. Root and Handler still render no DOM — the skin reads `useStatus` / `useController` and owns `data-slot` visuals.

## Out of scope

Common artifact deltas (`data-id`, `data-title`, `data-kind`, `data-clear`, `data-finish`) are treated like every other part. **[ArtifactSession](/docs/artifact-session)** owns applying that protocol.
