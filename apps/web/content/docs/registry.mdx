This repo uses **model C**:

- **npm** `@aisdkagents/react` — canonical headless behavior
- **shadcn registry** — styled adapters + composition examples that depend on the npm package

## Build locally

From the monorepo root:

```bash
pnpm registry:build
```

Sources live in `apps/web/registry/`. JSON is written to `apps/web/public/r/`.

## Install an item

After the docs site is deployed (or any host serving `public/r`):

```bash
npx shadcn@latest add https://<your-deployed-host>/r/data-stream-controller-demo.json
npx shadcn@latest add https://<your-deployed-host>/r/artifact-session-demo.json
```

Or, once the GitHub repo is public, follow [shadcn GitHub registries](https://ui.shadcn.com/docs/registry/github) using this repo’s root `registry.json`.

## Items

| Name | Type | Notes |
| --- | --- | --- |
| `data-stream-controller` | `registry:ui` | Frame / Status / Log / Clear skin |
| `artifact-session` | `registry:ui` | Panel skin via `createArtifactSessionSkin` |
| `data-stream-controller-demo` | `registry:component` | Skin + Root / Handler composition |
| `artifact-session-demo` | `registry:component` | Transport + session + panel composition |
